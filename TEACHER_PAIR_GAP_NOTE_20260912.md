# Relative-logit supervision and output-head pilot, September 12

This is a new empirical objective, not a proof of OPD suppression. Teacher training obeys TEACHER_ONLY_TRAINING_CONTRACT.md. No student parameters, scores, rewards, gradients, or simulated updates enter it.

For an offline foreign CoT prefix, the original teacher selects two highest eligible non-special logits a,b. Let g0 = log p0(a|c) - log p0(b|c). The Top2 permutation target asks for g* = -g0. The new negative loss is Huber_beta=1(log p_theta(a|c) - log p_theta(b|c) - g*), averaged over up to eight selected positions. Positions are selected with the original teacher's target KL, as before. The implementation obtains the changed pair from the original and permuted distributions; numerically negligible ties are skipped.

Because log p(a)-log p(b)=z_a-z_b, this loss is invariant to a common shift of all logits. Its direct output-logit derivatives on unrelated tokens cancel. It supervises relative evidence between the two candidates without requiring a full-vocabulary distribution match. This may reduce the burden of fitting a permuted distribution, but it also leaves total mass and other token scores unconstrained. Hidden-layer updates can change all logits and other contexts. It provides no guarantee of teacher answer accuracy, off-policy behavior, or student damage. KL and Huber weights are not numerically equivalent even when the same coefficient is used.

CPU checks cover gradient direction, exact-target zero loss, common-logit-shift invariance, and identity/tie skip. A diagnostic float conversion emits a PyTorch requires_grad warning; it is logging only and does not replace the differentiable loss. Existing real two-update smoke and ordinary-checkpoint export checks are required before formal training. The helper is not inserted into inference.

Three Top2 pilots complete a conceptual parameterization/objective comparison with the existing last-layer/full-KL anti1.5 control (main400 student45.5, expanded1000 student48 and teacher expanded greedy failure): head/full-KL, last-layer/pair-gap, head/pair-gap. They start from original7B and retain64 steps, anti1.5, anchor12, answerCE1, own-correctnessRL2, LR5e-6, warm16/ramp48. Head-only versions assert untied embeddings and whitelist lm_head parameters; input embeddings are frozen. This is distinct from historical low-mass tail flattening head experiments, which only achieved main40049.75.

The successful secondary-rank permutation pilots motivate three additional direct experiments: last2 anti4->2 with anchor24; last2->head with anti4/anchor24; and own correctness RL2->8 with last2/anti4/anchor24. All start from original teacher. The original last2/anti4/anchor24 main40044.0 and lastlayer/anti8/anchor24 main40044.5 need expanded evaluation before any reliability claim. Their frozen student extra600 and teacher new400 extensions are running alongside the Top2 hard-question RL main40045.0 extension.
